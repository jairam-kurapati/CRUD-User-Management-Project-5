# 🤖 AI User Management System

A modern CRUD (Create, Read, Update, Delete) web application built using **Python Flask**, **Machine Learning**, **HTML**, **CSS**, and **JavaScript**.

This project allows users to add, view, edit, and delete user records while automatically predicting a category using a Machine Learning model based on age.

---

## 📌 Features

### CRUD Operations
- ➕ Add User
- 📋 View Users
- ✏️ Edit User
- ❌ Delete User

### Machine Learning Integration
Predicts user category based on age:

| Age Range | Category |
|------------|-----------|
| < 18 | Student |
| 18 - 30 | Young Professional |
| 31 - 50 | Professional |
| > 50 | Senior Citizen |

### Modern UI
- Responsive Design
- Glassmorphism Effects
- Gradient Backgrounds
- Animated Buttons
- Hover Effects
- Mobile Friendly

### Additional Features
- 🔍 Search Users
- 📊 Sort by Age
- 🌙 Dark Mode
- 🔔 Toast Notifications
- ⚡ AJAX Requests (No Page Reload)
- 🪟 Edit Modal
- ⚠️ Delete Confirmation Modal
